Section 02

Install Guide

Option A — Cowork / Claude desktop Easiest
  • Download the full plugin above or a role-only package from the catalog below.
  • Drag & drop the file into any Claude chat.
  • Claude confirms the installation. The full package exposes 12 skills; a role package exposes exactly one.
Option B — Claude Code (one copy / one paste) Recommended

Run these inside a Claude Code session — the terminal CLI, the desktop app, or the coding agent, where Claude has a shell on your machine and installs the plugin for you. They will not install from a plain claude.ai chat, which runs in a sandbox with no access to your Claude Code setup. Copy the full-handbook command from the card above, or a role command below. Each command adds the marketplace if needed, then performs a persistent install.

claude plugin marketplace add thienbitcoin2020/myhandbook; claude plugin install project-handbook@power-home-handbook

The short command claude plugin install project-handbook@power-home-handbook works after this marketplace has already been added.

💡
Use one installation scope only. The full plugin already includes every role; role packages are for users who need a smaller, focused context.
