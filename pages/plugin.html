Section 02

Install Guide

Option A — Cowork / Claude desktop Easiest
  • Download project-handbook.plugin with the button above.
  • Drag & drop the file into any Claude chat.
  • Claude confirms the installation — the 12 skills then trigger automatically whenever a request matches a role.
Option B — Claude Code (CLI)

Run in the folder where you saved the download:

claude plugin install ./project-handbook.plugin

Manual alternative — the file is a standard ZIP; extract it into your plugins folder:

Expand-Archive project-handbook.plugin ~\.claude\plugins\project-handbook
unzip project-handbook.plugin -d ~/.claude/plugins/project-handbook
💡
No configuration needed. Skills describe their own triggers, so Claude picks the right role from your request — ask a BA question, get the BA skill.
